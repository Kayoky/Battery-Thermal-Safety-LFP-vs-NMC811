# Experimental data setup and reproducibility

This repository contains a secondary analysis of published experimental measurements from:

Schöberl et al., *Thermal runaway propagation in automotive lithium-ion batteries with NMC-811 and LFP cathodes: Safety requirements and impact on system integration*, eTransportation 19 (2024), 100305. DOI: `10.1016/j.etran.2023.100305`.

Original dataset DOI: `10.14459/2023mp1717758`.

## Obtaining the input data

Obtain the original dataset from the cited research data repository, subject to its access and reuse conditions. This repository does not redistribute the original measurement files. Arrange the extracted, chemistry-specific measurements in the directory layout below. The file naming and directory conventions shown are those expected by the Python scripts; the original download may require manual reorganization.

```text
project-root/
├── scripts/
├── data/
│   ├── LFP/             # T1_LFP.txt, T2_LFP.txt, ...
│   ├── NMC811/          # T1_NMC811.txt, T2_NMC811.txt, ...
│   ├── voltage/
│   │   ├── LFP/         # U-channel .txt files
│   │   └── NMC811/
│   ├── venting/
│   │   ├── LFP/         # V1_LFP.txt, ... V5_LFP.txt
│   │   └── NMC811/
│   └── surface/
│       ├── LFP/         # IR-derived .txt or .csv files
│       └── NMC811/
├── data_cleaned/        # Generated by script 03
└── results/             # Generated analysis outputs; selected outputs also tracked
```

The scripts generally expect CSV-formatted text files with headers, even when their extension is `.txt`. Temperature-processing scripts use columns such as `Time [s]` and `Temperature [°C]`. Confirm that the downloaded data uses the expected naming and headers before running the pipeline.

## Running the analysis

From the project root, create a Python environment and install dependencies:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Run the numbered scripts in ascending order, beginning with inspection and temperature cleaning:

```bash
python scripts/01_inspect_data.py
python scripts/02_plot_temperatures.py
python scripts/03_clean_temperatures.py
```

Continue with scripts 04 through 24, including the numbered 20.1, 20.2 and 20.3 scripts, in their intended sequence. Several later scripts consume CSV outputs produced by earlier steps. Do not treat the presence of previously committed result CSVs as proof that a fresh execution has succeeded.

**Important:** `scripts/25_generate_project_documentation.py` rewrites `README.md`, `FINAL_ENGINEERING_REPORT.md` and `requirements.txt`. Do not run it unless you intend to regenerate these files and have backed up the integrated Python/MATLAB documentation.

## Scope and limitations

The published plots and result CSVs allow inspection of the reported analyses without downloading the original measurements. Full reproduction of the experimental-data pipeline requires the original data and matching input-file layout. Algorithmic thermal-runaway onset times are preliminary and should not be interpreted as independently validated experimental event annotations. MATLAB/Simulink thermal-network and propagation models are illustrative and not experimentally calibrated.
